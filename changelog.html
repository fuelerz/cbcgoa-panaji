Project: CBC Goa V2

Date: August 2026

Version 2.0.0 Release — Classic Business Centre Goa

Major modernization update focusing on clean UI architecture, removal of heavy asset galleries, streamlined quote workflows, branch-aware WhatsApp routing, and professional frontend prerequisites.

Detailed Change Ledger
  • Removed

    Gallery & Workshop Photo Sections

    Completely stripped all shop interior and production floor image cards from the homepage to focus exclusively on clean service discovery and branch navigation.

  • Removed

    Static Pricing Tables

    Removed rigid pricing tables and fixed rate cards from the public view per client instructions, directing rate inquiries directly through counter consultations and WhatsApp.

  • Added

    Branch-Aware WhatsApp Routing

    Implemented smart switch-case logic in JavaScript to dynamically route client print requests to the correct branch WhatsApp contact based on dropdown selection, complete with a central fallback placeholder.

  • Added

    Verified Branch Roster & Local SEO

    Updated branch network strictly to the 4 verified Goa locations (Panaji Patto, Panaji MG Road, Porvorim, and Mapusa - removing Margao) and integrated LocalBusiness JSON-LD schema markup.

  • Added

    FAQ & Custom 404 Error Page

    Added an interactive FAQ accordion section covering file formats, turnaround times, and pickups, plus a custom branded 404 error page (`404.html`) to fulfill static software engineering prerequisites.
