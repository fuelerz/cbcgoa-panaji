# Classic Business Centre Goa (CBC V2)

The modern, high-converting digital storefront and print-request platform for **Classic Business Centre Goa (cbcgoa.com)**.

## 🚀 Overview

CBC V2 reimagines the local print-shop website into a high-performance, technology-enabled web app. Built with clean vanilla technologies, it features an editorial SaaS-level design system, branch-aware WhatsApp routing, real-time service search, and a streamlined paper & media rate catalogue.

## ✨ Key Features

* **Branch-Aware WhatsApp Routing:** Dynamically routes print requests and queries to the correct branch WhatsApp contact based on user selection, with a fallback placeholder.
* **Instant Rate Catalogue:** Filterable and searchable table for card stocks, textures, metallic finishes, stickers, and large-format printing.
* **Live Service Filter & Search:** Real-time search and categorization for everyday copying, design, jumbo printing, flex/vinyl, binding, lamination, and offset printing.
* **Adaptive Dark Mode:** Seamless toggle between light mode and a deep ink-green dark mode with persistent user preference storage.
* **Zero Dependencies:** Pure HTML5, CSS3, and vanilla JavaScript for lightning-fast performance and effortless static hosting.
